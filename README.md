# Authority Permit LLC website

Static HTML, CSS and JavaScript. GitHub Pages publishes the root of `main` at https://authoritypermit.com/. The quote form uses the existing Formspree endpoint in `contact.html`.

## Publish a journal post

Open `journal.html` in GitHub and add an `article.journal-entry` at the top of `.journal-posts`. Use a unique `id` and a `data-post` value of `article`, `update`, or `social`. Add a heading, summary, and optional image. For a social post, include a link to the original Authority Permit post and a short caption so the entry works without third-party scripts. Use the existing entries as examples. The journal filters pick up new entries automatically.

## Add reviews

Add real client feedback to the customer reviews section of `reviews.html` after receiving permission to publish the quote and any identifying details. Use the customer's actual words and add the source when available.
