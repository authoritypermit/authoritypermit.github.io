Common questions

Can you help if I already applied?

Send your application number and the latest correspondence. We’ll review what’s outstanding and discuss where we can help.

How long will review take?

Review timing depends on the jurisdiction, project scope, and any corrections requested. We can update you as the application moves through review.

What if I don’t know the permit type?

Describe what you’re planning and where. We can research which department to contact and what it asks for.
